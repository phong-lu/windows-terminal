# AI Contributions

This project is heavily contributed to by AI. AI tools are used extensively to design, write, review, test, and maintain its code and documentation.

AI contributions are welcome. Humans directing or submitting work remain responsible for its accuracy, quality, and appropriateness.

Agents should carry out requested work and run relevant checks. Do not request repeated declarations that the user personally reviewed or tested changes. Do not assume human verification has occurred or claim it on the user's behalf.
